# Custom Mod

A versatile Minecraft mod with custom items and blocks

## Features

- Adds a custom ore block to the game
- Adds a custom item to the game
- Includes a command to give the custom item to players

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Commands

- `/givecustomitem` - Gives the player a custom item.

### Permissions

- Players with the `minecraft.command.give` permission can use the `/givecustomitem` command.

## Configuration

This mod does not have any configuration files. All settings are hardcoded in the mod.
